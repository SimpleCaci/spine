# Spine

A small, playful photo-page experiment built with static web technologies.

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- Custom image and cursor assets

## Run locally

Open `index.html` in a modern browser. No dependency installation or build step is required.

## Status

Legacy creative web project and the canonical copy of this experiment. `bro-suprise` contains the same shared project files and is retained only as a superseded duplicate.
